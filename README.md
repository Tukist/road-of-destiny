# 命运之路 (Road of Destiny)

基于欧·亨利同名短篇小说的交互式文字冒险游戏。

> "我在路上寻找我未来的命运，带着真诚而坚强的心。" —— 大卫·米尼奥

## 玩法

你是韦尔努瓦村的牧羊诗人**大卫·米尼奥**。在月光下的三岔路口，三条命运之路等你选择——每条都通向截然不同的结局。

- **⬅️ 左路**：邂逅侯爵与露西小姐，卷入一场疯狂逼婚
- **➡️ 右路**：前往巴黎，陷进宫廷阴谋的漩涡
- **⬆️ 中路**：回到伊冯娜身边，过平凡但诗意的日子

## 快速开始

### 网站

https://road-of-destiny.onrender.com/

### Docker（推荐）

```bash
docker-compose up -d
# 访问 http://localhost:8000
```

### 直接运行

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 操作说明

当然你可以选择鼠标。

| 按键 | 功能 |
|------|------|
| `1-9` | 选择选项 |
| `↑↓` | 导航选项 |
| `Enter` | 确认 |

## 特性 (含剧透)

- 🖥️ **复古终端界面** — CRT扫描线、CRT噪点、等宽字体、动态配色主题
- ⌨️ **键盘操作** — 数字键选择、Ctrl加速、方向键导航
- 🔊 **Web Audio 音效** — 打字咔嗒、枪声、教堂钟声、马蹄声
- 🥚 **隐藏彩蛋** — 8+1 结局、各种作品Rick&Morty、极乐迪斯科致敬,terminal终端界面彩蛋--强制终止
- 💿 **道具系统** — 跳过键(Ctrl)、存档戒指(H/L)、死亡晶体结局观测(G)

| 按键 | 功能 |
|------|------|
| `Ctrl` | 加速文本（收集3彩蛋解锁） |
| `H` | 存储回溯点（收集6彩蛋解锁） |
| `L` | 读取回溯点 |
| `G` | 结局观测界面（收集9彩蛋解锁） |
| `R-I-C-K` | 解锁全结局后Rick传送门彩蛋 |
| `Ctrl+C` | 强制终止彩蛋 |
| `X` | 保留的后门调试按钮 彩蛋+1 |
| `A` | 保留的后门调试按钮 解锁全结局 |

如果你*不可挽回*地使用了调试按钮点击HOME回到主界面选择[ RESET ALL PROGRESS ]重新开始这一切吧
